Reduced Instruction Set Computing (RISC) is a CPU architecture philosophy that uses a **small, simple set of instructions** that can typically be executed in a single clock cycle.
The goal is to improve performance by simplifying the processor's design.

Key characteristics of RISC
- **Simple instructions** Each instruction performance one basic operation.
- **Fixed-length instruction** instructions are usually the same size, making decoding faster.
- **Load/store architecture** Only load and store instructions access memory; arithmetic and logical operations work only on registers.
- **Optimised for pipeline** Simple instructions allow multiple instructions to be processed simultaneously in different pipeline stages.

Advantages
- Faster execution due to simpler instructions.
- Easier to pipeline, improving throughput.
- Lower power consumption.
- Simpler hardware design, reducing manufacturing cost.

Examples of RISC processors
- ARM
- RISC-V
- MIPS
- SPARC
- PowerPC
