# Creating a stack from scratch

## Financial services web app

You are building a large app for a finance company. You need something trusted, secure, and easy to sell to management.

**Enterprise stack:**
- **Pure React + TypeScript** — UI
- **Apollo** — data fetching and cache
- **Styled-components** — styling

## Rapid prototype (task management tool)

You need to ship fast to show investors and early users. Speed matters more than a unique design.

**Prototype stack:**
- **Remix** — full-stack framework
- **Supabase** — backend and database
- **SWR** — client data fetching
- **Ant Design** — ready-made UI components

## Legacy enterprise dashboard

You maintain an older dashboard on classic React tooling.

**Old school stack:**
- **Create React App (CRA)** — build setup
- **Redux** — global state
- **CSS Modules** — scoped styles
