# x11

> X11 (the X Window System) is the legacy network-transparent display protocol — still common via Xorg or XWayland compatibility on Wayland sessions.

**X11** separates **X server** (owns GPU/input) from **X clients** (applications). The **window manager** decorates and focuses windows. Remote GUIs historically used `ssh -X` forwarding `DISPLAY`.

## Session variables

```bash
echo $DISPLAY          # e.g. :0 or :10.0 (SSH forwarded)
echo $XAUTHORITY       # cookie file for X auth
xset q                 # quick server reachability test
```

## Common tools

```bash
# Outputs and resolution
xrandr --query
xrandr --output HDMI-1 --mode 1920x1080 --rate 60

# Input devices
xinput list
xinput list-props 'Synaptics TouchPad'

# Window properties (WM_CLASS for rules)
xprop WM_CLASS
```

## XWayland

On Wayland desktops, X apps run through **XWayland** — an X server embedded in the compositor. Some features (global grabs, certain screen capture) behave differently than native Xorg.

## Troubleshooting

| Symptom | Check |
|---------|-------|
| `Can't open display` | `DISPLAY` set? `xhost` / `xauth` for remote |
| Wrong monitor layout | [[xrandr]]; persist in `~/.xprofile` or DE settings |
| High DPI blur | `Xft.dpi`, `GDK_SCALE` — prefer Wayland fractional scale if available |
| App only fails on Wayland | Force `GDK_BACKEND=x11` to test XWayland path |
