the `new` operation is essentially saying "JVM, I need storage for a new `User` object at runtime."

"The program's memory requirements are often determined by what happens at runtime, not entirely by what was known when the program was compiled."

You don't normally manually allocate/free heap memory. The JVM manages it using the **Garbage Collector (GC)**
