`ip` Base internet protocol used to carry IP packets.
`hopot` IPv6 Hop-by-Hop options header for information processed by routes along the pate.
`icmp` network control and error-reporting protocol, commonly used by `ping`.
`igmp` manages IPv4 multicast group membership
`ggp` Historical gateway-to-gateway routing protocol.
`ipencap` Encapsulates one IP packet inside another IP packet.
`st` historical datagram-oriented transport protocol
`tcp` Reliable, connection-oriented transport protocol used by HTTP, HTTPS, SSH, etc.
`egp` Historical protocol for exchanging routing information between autonomous systems.
`igp` Generic name for interior gateway routing protocols
`pup` historical Xerox/PARC network protocol suite.
`upd` Connectionless transport protocol commonly used for DNS, streaming, VoIP etc.
`hmp` Historical Host Monitoring Protocol.
`xns-idp` Xerox network systems internet datagram protocol
`rdp` Reliable datagram protocol providing reliable delivery over datagram network.
`iso-tp4` ISO transport protocol providing connectino-oriented transport services.
`dccp` Datagram transport protocol providing congestion control without TCP-style reliablity.
`xtp` Historical high-performance transport protocol.
`ddp` Apple talk datagram delivery protocol.
`idr-cmtp` control-message transport protocol associated with IDPR routing.
`ipv6` Internet protocol version 6 packet encapsulation.
`ipv6-route` IPv6 Routing header used to carry routing information.
`ipv6-frag` IPv6 fragment header used for packet fragmentation.
`idrp` Inter-Domain routing protocol for exchanging routing information between domains.
`rsvp` Resource reservation protocol used to reserve network resource for traffic flows.
`gre` Generic Routing Encapsulation used to tunnel network protocols inside IP.
`esp` IPsec protocol providing encryption, authentication, and integrity for IP packets.
`ah` IPsec protocol providing authentication and integrity without encryption.
`skip` Historical simple key-management for internet protocol.
